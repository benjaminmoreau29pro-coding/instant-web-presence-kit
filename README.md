Générateur de sites web statiques intelligent, ultra-rapide et entièrement personnalisable directement depuis une interface web fluide et dynamique. Conçu pour générer instantanément des packs de sites web prêts à l'emploi (comprenant structure HTML, styles CSS modernes, scripts JS et bundle .zip).

✨ Fonctionnalités Clés
🌐 Internationalisation (i18n) native : Support complet de 16 langues pour l'interface du générateur (Français, Anglais, Espagnol, Allemand, Chinois, Japonais, Coréen, etc.).

💼 Profils Métiers Avancés : Large sélection de secteurs d'activité pré-configurés (Développeur, Consultant, Avocat, Restaurant, Architecte, etc.) avec des styles et des contenus adaptés.

🎨 Palettes de Couleurs Dynamiques : Personnalisation instantanée du thème visuel à l'aide d'un sélecteur de couleurs interactif et application automatique sur l'interface et le site généré.

📱 Formats de Téléphone Intelligents : Gestion automatisée des indicatifs pays et validation stricte des formats de numéros de téléphone selon la région sélectionnée.

📦 Export ZIP Automatisé : Intégration de la bibliothèque JSZip pour empaqueter et télécharger instantanément le code source complet du site généré en un seul clic, animé par une fusée interactive.

🌓 Thèmes Clair / Sombre : Bascule fluide entre les modes Light et Dark avec des animations de fond dynamiques (particules / flocons lumineux).

🛠️ Stack Technique
HTML5 / CSS3 (Variables CSS dynamiques, Grid, Flexbox, animations fluides).

JavaScript (ES6+) (Architecture modulaire, gestion des formulaires, regex de validation, manipulation du DOM).

JSZip (Génération d'archives ZIP côté client).

📂 Structure du Projet
Plaintext
├── index.html       # Interface principale du générateur
├── script.js        # Logique applicative, dictionnaires i18n, validations et moteur d'export ZIP
├── profiles.js      # Configuration et métadonnées des profils métiers
└── style.css        # Styles globaux, thèmes dynamiques et animations (fusée, arrière-plan)
